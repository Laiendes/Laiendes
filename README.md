### 🚀 Featured Project

#### [Manutenciona — Maintenance Request Management API](https://github.com/Laiendes/manutenciona)

A RESTful API developed with PHP and Laravel to manage maintenance requests in shared environments.

**Key features:**

* Token-based authentication with Laravel Sanctum.
* Role-based access control.
* Maintenance request management and assignment.
* Controlled status transitions.
* Audit history and database transactions.
* Automated testing with Pest.

**Testing:** 56 passing tests and 218 assertions.
